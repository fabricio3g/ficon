Icons drawn for 16 pixels, each with its own motion.

Most sets are drawn at 24 and scaled down until the gaps close. ficon is drawn on the grid it renders at — bold strokes, few of them, and a small animation per icon that says what it does.

Install

Not on npm yet — install from GitHub, or just copy the files you need out of icons/ and dist/ficon.css.

npm i github:fabricio3g/ficon

Plain HTML

Click any icon above to copy its markup, and load the stylesheet once. The icon takes its colour from currentColor and animates when a parent button, a, label, summary or an element with role="menuitem | tab | option" is hovered. Without the stylesheet it is simply a still icon.

<link rel="stylesheet" href="ficon.css">

<button>
  <svg class="ficon ficon-trash-2" width="16" height="16" viewBox="0 0 16 16"
       fill="none" stroke="currentColor" stroke-width="1.5"
       stroke-linecap="round" stroke-linejoin="round" aria-hidden="true">
    <path class="a" d="M2.5 4.5h11M6 4.5V3a1 1 0 0 1 1-1h2a1 1 0 0 1 1 1v1.5"/>
    <path d="M4 4.5l.5 8A1.5 1.5 0 0 0 6 14h4a1.5 1.5 0 0 0 1.5-1.5l.5-8"/>
  </svg>
  Delete
</button>

Slim · 1

Motion

There is no shared wiggle. Each icon carries an animation that says what it does: the trash can lifts its lid, the check draws itself, the bell swings from its top, the download arrow drops into its tray.

  • Plays once per hover of the control it sits in.
  • Never longer than 300ms, never moves more than 2px.
  • Only translate, rotate, scale, opacity and stroke draw-on.
  • Off entirely under prefers-reduced-motion.

Play from code

Hover is the default trigger. To play an icon yourself — on success, on focus, on a timer — put ficon-play on the icon or any ancestor. Remove and re-add the class to play it again.

button.classList.remove('ficon-play');
void button.offsetWidth;            // restart
button.classList.add('ficon-play');

Anatomy of an icon

An icon is one file. The shapes come first; the <style> block at the end is its animation, written against the icon's own parts (.a … .f). The build lints every file, scopes each block to its icon and writes dist/ficon.css.

<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 16 16" fill="none"
     stroke="currentColor" stroke-width="1.5"
     stroke-linecap="round" stroke-linejoin="round">
  <path class="a" d="M2.5 4.5h11M6 4.5V3a1 1 0 0 1 1-1h2a1 1 0 0 1 1 1v1.5"/>
  <path d="M4 4.5l.5 8A1.5 1.5 0 0 0 6 14h4a1.5 1.5 0 0 0 1.5-1.5l.5-8"/>
  <style>
    .a { transform-box: view-box; transform-origin: 13.5px 4.5px;
         animation: lid 280ms ease-out; }
    @keyframes lid { 45% { rotate: 14deg; translate: 0 -1px; } }
  </style>
</svg>

Drawing rules

  • 16 × 16 grid, stroke centres inside 2 … 14, coordinates on the half pixel.
  • Air: parallel strokes keep their centres 3 apart. A detail that cannot is dropped, not squeezed in.
  • One idea per icon: two to four strokes, rarely six.
  • Optical size: a square is drawn smaller than a circle so the two weigh the same.
  • Families share a skeleton: every file-* is the same page with one mark in it.

The full rules, and how to add an icon, are in CONTRIBUTING.md.
